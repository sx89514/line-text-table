# line-text-table

在 LINE 對話的時候，有時候要告訴別人下週有空的時間，就會打出「我週二早上有空」「週三下午有空」「週五都可以」之類的話。

這個 Skill 會把這些話排成框線符號（┌┬┐│├┼┤└┴┘）表格，在 LINE 等社群軟體傳送時一目瞭然。

也不限於行程表，簡易報價也可以。

## 安裝

需要 Claude Code 或 Codex，以及 Python 3（用來檢查表格會不會歪）。

Claude Code：

```bash
git clone https://github.com/sx89514/line-text-table ~/.claude/skills/line-text-table
```

Codex：

```bash
git clone https://github.com/sx89514/line-text-table ~/.agents/skills/line-text-table
```

## 使用

開新對話，輸入 `/line-text-table`（Codex 用 `$line-text-table`），接著用平常講話的方式說：

- 「幫我排下週的空檔：週一整天可以、週三只有下午」
- 「幫我排報價表：基本 3000 元 3 天、標準 5000 元 5 天」

複製產生的表格，貼到 LINE 就可以了。

## 為什麼不會歪

LINE 手機版不是等寬字型，一般的純文字表格傳過去一定會歪。實測後整理出幾個規則：

- 框線符號、中文字、全形英數（`１５` `Ｏ` `Ｘ`）和 `●` 一樣寬，所以格子裡一律用全形字。
- 半形的數字、英文和空白比較窄，一混進去就會歪。
- 手機一行大約只放得下 13 個字，太寬會被自動換行，所以表格要夠窄。

排好後會先跑 `scripts/check_table.py` 檢查寬度和直線有沒有對齊，通過才交給你。
